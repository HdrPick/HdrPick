## 1. 产品概述

jietu-hdr 是一款面向 Windows HDR 生态的桌面工具，采用 Tauri 2 + Rust + Vue3（Naive-UI）构建，核心能力：

| 能力域 | 说明 |
|---|---|
| **真 HDR 截图** | DXGI 桌面复制捕获 scRGB/HDR10 原始亮度数据，经 BT.2390 等算子色调映射输出 SDR，或直存 HDR 格式（HDR PNG / JXL / JXR / EXR） |
| **录制动图** | JXL 动图（16bit PQ/BT.2020），GPU 帧去重、30 秒环形缓冲、游戏模式零编码录制 |
| **录制视频** | MKV 崩溃安全容器，H.264/HEVC 硬件编码，HDR10 直录（P010），追随鼠标、画中画、水印、计划录制 |
| **视频播放** | 独立原生播放器（PotPlayer 形态），D3D11 硬渲染，播放位置记忆 |
| **AI 放大** | waifu2x / Real-ESRGAN 原生移植，D3D11 Compute Shader 加速，与原版位级对拍 |
| **SDR→HDR** | HDRTVNet AI 逆色调映射 + 自然/鲜艳曲线档 |
| **看图器** | 25 种格式解码（含 PDF/PSD/EXR/JXL/JXR）、相册库、逻辑相册、隐私保险库（AES-256-GCM）、拼图、打印、批量处理 |
| **显示器控制** | HDR 开关、HDR 内容亮度（SDR 白）、WMI/DDC 亮度调节、面板色域检测 |
| **内存清理** | Mem Reduct 式 8 区域 NT 清理、阈值/间隔自动清理、托盘徽章 |

## 2. 系统要求与运行环境

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11（HDR 截图、Mica 材质、HDR10 直录建议 Windows 11） |
| 显示器 | SDR 即可工作；HDR 截图与真 HDR 查看需 HDR 显示器 |
| 显卡 | 可选：NVIDIA（NVENC）/ AMD（AMF）/ Intel（QSV）任一用于视频硬编与 AI 放大 GPU 加速；均无时自动回落 CPU 软编/软渲染 |
| 视频组件 | exe 同目录需存在 `ffmpeg\bin\`（avcodec-63.dll、avformat-63.dll、avutil-61.dll、swresample-7.dll、swscale-10.dll），设置页显示「视频组件：已就绪」 |
| AI 模型 | exe 同目录 `models\`（超分权重）；`models\itm\Ensemble_AGCM_LE.pth`（SDR→HDR AI 档） |
| OCR | 系统需安装至少一个 OCR 语言包（设置 → 时间和语言 → 语言 → 添加语言） |

**运行特性**

- 单实例：重复启动时参数（图片/视频/目录）自动转发给已运行实例。
- 配置持久化：`%APPDATA%\jietu-hdr\config.toml`。
- 日志：exe 目录 `jietu-hdr.log`（启动截断、运行期累加）。

## 3. 快速上手

1. 启动后主窗口自动打开（440×520，Win11 Mica 材质，12px 圆角）；关闭窗口默认最小化到托盘（可配置）。
2. 按 **Ctrl+Shift+S** 进入区域截图：悬停自动识别窗口（单击整窗截取），拖拽自由框选。
3. 选区后进入标注模式：画笔 / 文字 / 箭头 / 矩形 / 圆圈 / 马赛克（方块/高斯）/ 文字识别，Enter 复制、Ctrl+S 保存。
4. 按 **Ctrl+Shift+F** 全屏截图（弹预览）；按 **Ctrl+Shift+D** 静默截图（直接保存）。
5. 默认保存到 `图片\jietu-hdr\`，命名 `jietu_日期_时间`，默认 SDR PNG 格式并复制到剪贴板。

## 4. 主窗口

### 4.1 标题栏（TitleBar）

| 控件 | 功能 |
|---|---|
| ←（仅设置中心） | 返回主面板 |
| 图钉 | 窗口置顶切换 |
| 显示器面板（对比度图标） | 弹出面板：每显示器 HDR 开关、「HDR 内容亮度」滑杆（80–480 nits）、亮度滑杆（0–100）、面板原生色域信息（色域分类 / P3 覆盖% / BT.2020 覆盖% / 峰值 nits） |
| 太阳/月亮 | 主题切换：跟随系统 / 浅色 / 深色（联动浅色 Mica / 深色 Mica-Alt 窗口材质） |
| 最小化 / 最大化 / 关闭 | Win11 原生图标；「最小化到托盘」开启时关闭键被拦截为隐藏 |

### 4.2 主内容区

- 主按钮：**区域截图**（框选任意区域 · 单击识别窗口）。
- 次级按钮一排（7 个）：**全屏截图 / 静默保存 / 打开相册 / 打开图片 / AI 放大 / 录制视频 / 录制动图**。
  - 打开图片支持：png / jpg / jpeg / gif / bmp / webp / avif / tif / tiff / psd / ico / jxl / jxr / wdp / exr（另支持 pdf）。
  - 打开相册：直接调起看图窗口相册页。
  - AI 放大：打开独立批量超分窗口（`#/upscale`）。
- 可点状态条（chips，点击直达设置中心对应分组）：
  - **输出格式**（SDR PNG / HDR PNG / EXR / HDR JXL / HDR JXR / AVIF）→ 输出分组
  - **热键**（显示当前区域截图热键）→ 热键分组
  - **内存**（实时百分比每秒刷新；≥70% 橙、≥90% 红）→ 内存清理分组
  - **保存路径**（显示目录名，默认显示「图片库」）→ 输出分组
  - **QQ 交流群**（点击复制群号 1094033308）
  - **设置** → 设置中心

### 4.3 截图预览弹窗

全屏截图 / 另存为后弹出（受「显示预览」设置控制）：图片 + 文件名 + 尺寸，按钮「复制到剪贴板 / 打开所在位置 / 关闭」。

### 4.4 录制动图弹窗（JXL）

- 未录制：「游戏模式」开关（录制期间零编码不影响游戏帧数，停止后全核编码需等待）；提示「最长 30 秒 · 全屏 · HDR JXL 动图 · 画面静止时自动去重」；按钮「取消 / 开始录制」。
- 录制中：红点 + 计时 + 剩余秒数 + 游戏模式标签 + 进度条 + 统计（帧数 / 去重 / 缓冲或已编 / 淘汰）；按钮「放弃 / 停止并保存」。

### 4.5 录制视频弹窗（MKV）

- 未录制：编码（H.264 / HEVC）、帧率（30/60/120 fps）、音频（关闭 / 系统声音 / 系统+麦克风）、定时（N 分钟后开始，倒计时中可「取消定时」或「后台等待」）；按钮「播放视频 / 取消 / 开始录制」。
- 录制中：计时（支持小时）+ 已暂停标签 + 统计（fps / 帧 / MB / 丢帧）+ 静默倒计时提示；按钮「放弃 / 暂停·继续 / 停止并保存」。
- 完成动作为「关机」时弹「系统即将关机」对话框，可「取消关机」。

## 5. 截图功能

### 5.1 三种截图方式

| 方式 | 默认热键 | 行为 |
|---|---|---|
| 区域截图 | Ctrl+Shift+S | 隐藏主面板 → 全屏冻结背景覆盖层 → 选区 → 标注 → 保存/复制/贴图 |
| 全屏截图 | Ctrl+Shift+F | 隐藏主面板 → 整屏捕获 → 保存/复制 → 弹预览（恢复主面板不抢焦点） |
| 静默截图 | Ctrl+Shift+D | 直接捕获保存，无标注无预览；目标显示器可选「主显示器 / 鼠标所在显示器」 |

### 5.2 捕获管线（HDR/SDR）

- HDR 桌面：捕获 `R16G16B16A16_FLOAT`（scRGB 线性光，1.0 = 80 nits）或 `R10G10B10A2`（HDR10）原始数据，经管线：清洗 → 统一绝对 nits → 曝光 → 亮度驱动色调映射（默认 BT.2390）→ 亮度等比缩放 → 饱和度 → 色域压缩 → sRGB OETF → 对比度 → Bayer 抖动量化。
- SDR 桌面：捕获 `B8G8R8A8_UNORM`，走系统转换（与 QQ 截图一致）。
- Win10 黑帧容错：黑帧检测 → 等待真实呈现帧 → 仍黑自动 GDI BitBlt 兜底。
- SDR 白电平经 DisplayConfig 读取系统「SDR 内容亮度」滑块实际值参与映射；HDR 期的参考白会被记忆，供 SDR→HDR 编码还原。

### 5.3 区域选择交互（RegionSelectOverlay）

- **冻结背景**：QQ 式后台预截图 + 全屏 30% 遮罩 + 选区挖空 + 主题色蚂蚁线。
- **窗口识别**：悬停高亮窗口边界 + 尺寸标签，**单击 = 截取整窗**；拖拽超过 4px = 自由框选。
- **放大镜**：136px 方形 6 倍放大、中心红十字线、物理像素坐标条，屏幕边缘自动翻转。
- **尺寸提示**：`宽 × 高（约分比值）`（自动搜索最接近小整数比）。
- 快捷键：**Enter = 复制到剪贴板**、**Ctrl+S = 快速保存**、**Esc = 分层取消**（先清选区再退出）、**右键 = 分层回退/退出**。
- 选区可拖动、8 控制点缩放；选区外点击重新选区。
- 另存为格式跟随输出设置，默认名 `jietu_时间戳.扩展名`。
- 安全机制：前端每秒心跳，渲染假死 8 秒后端强制收起覆盖层。

### 5.4 标注工具（工具栏出现在选区下方，可拖动、可收起为小圆点）

| 工具 | 说明 |
|---|---|
| 选区 | 移动/缩放选区 |
| 画笔 / 文字 / 箭头 / 矩形 / 圆圈 | 基础绘制 |
| 马赛克 | 方块马赛克 / 高斯模糊双模式 |
| 文字选项 | 字体：Segoe UI / 微软雅黑 / 宋体 / 黑体 / 楷体 / 等线；字号 12–48px 共 10 档 |
| 调色板 | 6 色：豆沙红 #D89898（默认）/ 香芋紫 / 薄荷绿 / 雾霾蓝 / 奶茶棕 / 浅灰 |
| 粗细 | 滑块 1–20px + 实时圆点预览 |
| 操作 | 撤销 Ctrl+Z / 重做 Ctrl+Shift+Z / 复制 Enter / 保存 Ctrl+S / 另存为 / 贴图 / 文字识别（OCR） |

**OCR 文字识别**：工具栏「文字识别」后，框选识别出的文本 Ctrl+C 复制（或「复制全部」）；识别语言在设置页配置（默认自动：zh-Hans > zh-Hant > zh-* > en-US 优先）；引擎为 Windows.Media.Ocr，返回行/词级坐标供叠加。系统未装语言包时给出系统设置路径提示。

### 5.5 贴图（PinWindow）

- 标注工具栏「贴图」将截图钉在桌面：独立无边框透明窗口、默认置顶、左键拖动、滚轮缩放（±5%/格，0.1×–5×）、左下角缩放百分比。
- 鼠标移入显示右上控制点（1.5s 无操作淡出）：置顶切换 / 关闭。
- 可由设置「启用贴图」整体隐藏入口。

### 5.6 保存与输出

- 保存目录：默认 `图片\jietu-hdr\`（可自定义）。
- 命名：`filename_template` 模板，`{date}`=%Y%m%d、`{time}`=%H%M%S、`{index}` 恒为 001；默认 `jietu_{date}_{time}`。
- 每张截图伴随**同名 .txt 参数 sidecar**（记录 HDR→SDR 出图参数链，可追溯）。
- 复制到剪贴板（带重试）、提示音（MessageBeep Asterisk，默认关）。
- 「截图自动 AI 2x 增强」（默认关）：后台生成 `<文件名>_waifu2x_x2.png` 增强副本，不替换原图、不阻塞截图。

## 6. 录制动图（JXL）

### 6.1 基本规格

| 项目 | 规格 |
|---|---|
| 产物 | `record_YYYYMMDD_HHMMSS.jxl`（16bit PQ / BT.2020），保存到录屏目录（默认沿用截图目录） |
| 时长 | 上限 30 秒（1–30 可配），到时自动停止 |
| 帧率 | 自动（30fps，与回放速率匹配）/ 60 / 30 / 24 fps |
| 质量档 | 无损 / 极高 / 高（默认，速度体积平衡）/ 均衡 / 紧凑 |
| 去重 | GPU 哈希帧去重自动开启，静止画面不占缓冲 |
| 暂停 | 无（仅 开始/停止/放弃） |

### 6.2 游戏模式（沉浸式录制）

- 热键 **Alt+F9** 直启：全屏 + 游戏模式 + OSD，不切出游戏（连按防重入）。
- **静默延迟启动**：默认 5 秒（0–10 可配），OSD 静默倒计时给用户切回游戏的时间，不抢焦点；倒计时期间按停止键 = 撤销启动。
- OSD：240×44 透明置顶胶囊（右上角 16px 边距），点击穿透、不被截入、每 500ms 置顶看护；四态：倒计时 → 录制中（计时+剩余）→ 编码中 → 完成/错误（2.6s 自毁）。
- 停止热键 **Alt+F10**（录制期间临时注册）；被占用时 OSD 提示用面板停止。
- **游戏模式 = 纯录制**：录制期间零编码（CPU 全归前台游戏），停止后全核编码（30s 素材约需 1 分钟，退出保护最长等 180s）。
- 采集后端：`auto`（游戏模式 WGC 优先 + DDA 兜底；桌面录制 DDA）/ 强制 `wgc` / 强制 `dda`；采集失效自动重建（最多 3 次）录制不中断。

### 6.3 播放（JXL 动图工具条）

- 看图器打开 .jxl 动图 → 独立原生播放窗口（无限循环、空格暂停、自动全屏）。
- 解码后端：`native`（纯 CPU libjxl，默认最稳）/ `hybrid`（GPU 混合，实验性，异常自动回退）。
- 播放模式：`gpu`（GPU 常驻显存池，默认）/ `ring`（内存环形缓冲）；显存预算默认自动（min(4096MB, 专用显存 50% − 512MB)）。
- 悬浮工具栏（光标移入显示，暂停时常显）：
  - 播放/暂停（空格）
  - 帧步进：−10 −5 −3 −1 +1 +3 +5 +10（←/Ctrl+←/Shift+←/Ctrl+Shift+← 及右向同构）
  - 秒级跳转：−3s −1s +1s +3s（PgUp/PgDn/Shift 组合）
  - 导出当前帧 **PNG**（PrtSc，HDR PNG）/ 导出 **JXL**（Ctrl+PrtSc）
  - 全屏切换（F11）

## 7. 录制视频（MKV）

### 7.1 编码与容器

| 项目 | 规格 |
|---|---|
| 容器 | MKV，EBML 流式增量写盘，**崩溃安全**（残缺文件可播放，Cues 停止时回填） |
| 编码格式 | H.264（兼容性最好，默认）/ HEVC（同画质更小）；**HDR 直录强制 HEVC main10** |
| 硬件编码 | 自动探测链 nvenc → amf → qsv → libopenh264 软编；可强制 NVIDIA NVENC / AMD AMF / Intel QSV / CPU 软编 |
| 帧率 | 30 / 60（默认）/ 120 fps（内部钳制 10–144） |
| 码率 | 8 / 12 / 16 / 20（默认）/ 30 / 50 Mbps |
| 音频 | 关闭 / 系统声音（WASAPI 回环，默认）/ 系统+麦克风混录 |

**HDR10 直录**：目标显示器为 HDR 时自动走 P010 路径（scRGB → GPU 转 PQ/BT.2020/BT.2100 NCL → HEVC 10bit）；显示器非 HDR 自动回落 SDR。

### 7.2 录制模式

| 模式 | 说明 |
|---|---|
| 全屏（默认） | 目标显示器可选（枚举列表，0 = 主显示器） |
| 追随鼠标 | 裁剪窗默认 1280×720（64–4096 可调，自动偶数化），每帧窗口居中光标并钳制在显示器内 |

### 7.3 画面叠加

| 叠加项 | 默认 | 说明 |
|---|---|---|
| 鼠标指针 | 开 | DDA 帧不含指针，软件叠加（彩色/单色光标均支持） |
| 点击效果 | 关 | 左键青圈 / 右键红圈，0.5s 扩散 |
| 高亮效果 | 关 | 点击点半透明色块 1s 渐隐；颜色 #FFD400（默认）/ 边长 120px（16–300） |
| 水印文字 | 空 | `\n` 多条；`{ts}` = 本地时间戳；字号 12–72（默认 24） |
| 水印图片 | 空 | PNG；不透明度烘入 |
| 水印位置/不透明度/边距 | 右下 / 100% / 16px | 九宫格 tl…br |
| 摄像头画中画 | 关 | Media Foundation 采集；显示宽 320px（0=自适应 1/4 宽）、九宫格位置、边距 16、水平镜像、**色度键抠像**（键色 #00FF00、相似度 0–100 默认 60）；设备打开失败降级继续录 |

叠加层次：光标 → 水印 → 摄像头（最上层）。

### 7.4 自动停止 / 分卷 / 计划 / 完成动作

| 功能 | 说明 |
|---|---|
| 时长上限 | 秒（0 = 不限）；按媒体时长判定，暂停期不计时 |
| 大小上限 | MB（0 = 不限） |
| 静默自动停止 | 持续无声 N 秒触发 → 倒计时（默认 10s，1–120）→ 期间声音恢复自动取消续录；仅音频开启时有效 |
| 分卷 | GB 阈值（0 = 不分卷）；超阈值无缝切新文件 `{原名}-partN.mkv` |
| 计划录制 | 30s 轮询调度：重复 一次 / 每天 / 每周（选星期）；开始/结束时间 HH:MM；结束时间换算时长上限自动停止；once 触发后自动关闭 |
| 定时启动 | 面板「N 分钟后开始」，倒计时可取消 |
| 完成动作 | 无 / 录新视频（1.2s 后自动重开）/ 退出程序 / **关机**（倒计时默认 30s，5–600 可调，可取消） |

### 7.5 交互与热键

- **Alt+F7** 游戏模式直启；**录制中再按 = 暂停/恢复切换**；**Alt+F8** 停止（录制期间临时注册；未配置则热键直启拒绝启动）。
- 视频 OSD：260×44 同动图 OSD 特性；计时（暂停琥珀点）+ 体积 + 丢帧 + 静默倒计时。
- 与 JXL 动图录制**全局互斥**（任一在录则另一个拒绝启动）。

### 9.3 参数

| 参数 | 说明 |

### 9.4 性能与输出

- **GPU**：D3D11 Compute Shader（硬件失败回落 WARP 软渲染，再回落 CPU）；显存自适应分块（默认 256，自动降 128/96/64）。

- 输出命名：`<原名>_waifu2x[_noiseN][_x倍率 | _w宽x高].<ext>`，同名自动追加 `_1`、`_2`…。

- 批量进度事件 `upscale://progress`（逐张开始/完成/失败/取消/汇总）；「基准测试」对比 GPU vs CPU 耗时。
- 输入目录批量枚举仅 png/jpg/jpeg/webp，自动跳过含 `_waifu2x` 的既有输出。

## 10. 看图器

### 10.1 支持格式

**SDR 常规格式**（浏览器原生直载）：PNG、JPEG、GIF（动画）、BMP、WebP、AVIF。

**二级/三级解码**（转临时 PNG 呈现）：TIFF、ICO、PSD（8bit，图层合成）、PDF（WinRT 渲染，多页翻页）。

**HDR 格式**（色调映射为 SDR 预览，源数据不动，可真 HDR 查看/重渲）：

| 格式 | 解码路径 |
|---|---|
| HDR PNG（16bit PQ + cICP） | cICP 检测 → PQ EOTF → BT.2020/P3→BT.709 → 色调映射 |
| OpenEXR | 32bit 浮点线性 → scRGB → 色调映射 |
| JPEG XL（JXL） | libjxl：SDR 直出 / HDR PQ 管线 / float 线性；动图另走播放器 |
| JPEG XR（jxr/wdp） | WIC：SDR 直出 / 浮点 HDR 家族 → 色调映射（Windows HDR 壁纸格式） |

目录列表白名单：png/jpg/jpeg/gif/bmp/webp/avif/tif/tiff/ico/psd/jxl/exr/jxr/wdp/pdf。

### 10.2 查看交互

### 10.3 真 HDR 查看 / 亮度调节 / SDR→HDR

- **真 HDR 查看**（HDR 源 + HDR 屏）：嵌入原生 scRGB FP16 交换链（1.0 = 80 nits 绝对亮度，1000 nits 高光真实点亮），保留全部 WebView 工具栏；滚轮缩放、拖拽平移、双击 1:1/自适应、F11 全屏、Esc 关闭；标题栏显示峰值 nits。

### 10.9 回收站

- 删除 = 移入 `%APPDATA%\jietu-hdr\recycle\`，**7 天自动过期清理**。

### 10.10 隐私相册（保险库 Vault）

- 加密：**AES-256-GCM**（索引与图片独立随机 nonce）；密钥 **PBKDF2-HMAC-SHA256 12 万迭代**派生；主密钥绝不下发前端。
- 流程：创建（密码二次确认）→ 锁定/解锁 → 添加图片（加密后删除源文件，失败自动回滚）→ 解密临时查看（锁定时清除）→ 恢复到原位置 / 永久移除 / 修改密码（两阶段重加密，失败整体回退）。
- 5 分钟无操作自动锁定；全局热键 **Ctrl+Shift+L** 唤起；资源管理器右键「添加到 jietu 隐私相册」。

### 10.11 其他

- **EXIF 面板**：6 组中文分组（设备与拍摄/曝光/镜头/图像属性/GPS/时间），GPS 十进制度 + 度分秒，一键复制全部。

- **复制到剪贴板**：GIF 走 CF_HTML（QQ/微信粘贴保留动画）；webp 动图取首帧。
